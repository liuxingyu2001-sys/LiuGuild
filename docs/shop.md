# 工会商店

工会商店仅出售实际库存，**只供本会成员购买**；购买使用买家自己的**个人工会资金**支付，
扣税后的货款进入**卖方工会的点数**（公共工会资金）。商店不使用 Vault 金币，也不动工会银行。

## 工会隔离

- 上架记录以 `guild_id` 归属工会，每个工会的商店物品**完全独立**。
- 商店只展示 / 购买**本会自己的**上架；工会之间不能互相看到或购买对方的商品。
- 因此不再提供“全服工会商店”（旧的 `/guild shop all` 已移除）。
- 每个工会独立计算上架上限，配置 `guild.shop.max-listings`（默认 **10**）。

## 货币

| 项目 | 说明 |
|---|---|
| 支付 | 买家的**个人工会资金**（签到获得，见 [funds.md](funds.md)） |
| 入账 | 卖方工会的**点数**（公共工会资金） |
| 税 | `guild.shop.tax-percent`，按比例从货款中扣除（`0` 表示全额入账） |
| 不使用 | Vault 金币、工会金币银行 |

购买者与卖方是同一工会的成员，因此一次购买等价于“个人资金按标价换成物品，同时给工会补充点数”。

## 操作

| 操作 | 功能 |
|---|---|
| `/guild shop` | 打开本会商店 |
| `/guild shop list` | 文字列表 |
| `/guild shop add <工会资金单价>` | 上架手持物品 |
| `/guild shop remove <编号前8位>` | 下架并退回剩余库存 |
| 左键商品 | 输入数量购买 |
| Shift + 左键 | 修改售价（需管理权限） |
| Shift + 右键 | 下架（需管理权限） |

管理条件为 `liuguild.shop.manage` 权限或达到 `guild.shop.manage-rank` 职位。商品按每页 28 个展示，底栏提供翻页与返回主页。

上架上限：每个工会最多 `guild.shop.max-listings` 条（默认 10），达到上限时 `addListing` 返回 `shop-listing-limit`。

## 收购已取消

不再提供收购、付费供货或收购价输入。旧数据库的 `buy_price` 列仅保留兼容，加载时忽略；旧 `supply` 服务调用也不会转移任何金币或物品。右键不会触发出售。

LiuShop 集成仍用于**禁售检查**（上架前拦截被禁物品）；不再给出建议售价，因为货币不同。

## 交易一致性

购买在数据库**同一事务**中完成三件事，任一步失败都整体回滚：

1. 扣买家个人工会资金（余额不足或已非该会成员 → 拒绝）；
2. 原子扣库存（报价被并发修改或库存不足 → 拒绝）；
3. 税后货款记入卖方工会点数（溢出保护）。

因此不存在“扣了钱没拿到货”或“发货了没给工会入账”。个人资金扣款本身有独立余额与成员身份校验，
仓库/资金的既有约定见 [funds.md](funds.md)。

**崩溃恢复：** 上架、下架、购买会先写 `liuguild_shop_pending` 交接记录，并在数据库事务中把记录推进到 `DONE/READY`。
若在「数据库已提交、物品还没发放」之间崩溃，玩家下次上线会继续发货；未完成的记录会保留待处理，不会静默吞物品。

**部署注意：所有子服同时更新，不能让仍支持收购或按 Vault 金币定价的旧版继续访问同一数据库。**
