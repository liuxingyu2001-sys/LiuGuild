# 工会商店

工会商店仅出售实际库存，任何玩家可购买；货款使用 **Vault 金币**，扣税后进入卖方的**工会金币银行**，不是工会建设资金。

## 操作

| 操作 | 功能 |
|---|---|
| `/guild shop` | 打开本会商店 |
| `/guild shop all` | 浏览全服商品 |
| `/guild shop list` | 文字列表 |
| `/guild shop add <金币单价>` | 上架手持物品 |
| `/guild shop remove <编号前8位>` | 下架并退回剩余库存 |
| 左键商品 | 输入数量购买 |
| Shift + 左键 | 修改售价（需管理权限） |
| Shift + 右键 | 下架（需管理权限） |

管理条件为 `liuguild.shop.manage` 权限或达到 `guild.shop.manage-rank` 职位。商品按每页 28 个展示，底栏提供翻页、切换商店与返回主页。

## 收购已取消

不再提供收购、付费供货或收购价输入。旧数据库的 `buy_price` 列仅保留兼容，加载时忽略；旧 `supply` 服务调用也不会转移任何金币或物品。右键不会触发出售。

LiuShop 集成仍可提供禁售检查和建议售价，不代表开启工会收购。

## 交易一致性

- 购买先扣买方 Vault 金币；数据库在同一事务中校验报价、扣库存、入账工会金币；失败不发货并尝试原额退款。
- 下架锁定数据库条目，以真实剩余库存退货；重复下架不会重复退回缓存库存。
- 资金捐献与商店无兑换关系，见 [funds.md](funds.md)。

**部署注意：所有子服同时更新，不能让仍支持收购的旧版继续访问同一数据库。** Vault 与 SQL 无法形成同一数据库事务，进程崩溃窗口及经济插件退款失败仍需运维核查；不能将单元测试视为完整交易故障恢复验证。
