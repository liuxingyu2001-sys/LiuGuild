# 工会限时增益

主菜单「工会增益」打开购买面板。默认仅会长可购买，费用扣公共工会资金；所有本会成员（含之后加入者）共享剩余时间。普通成员可查看效果与剩余时间。

## 默认效果与费用

| 增益 | 效果 | 时长 | 公共资金 |
|---|---|---|---|
| 疾行祝福 | 速度 I | 1小时 | 1000 |
| 矿工祝福 | 急迫 I | 1小时 | 1500 |
| 深海祝福 | 水下呼吸 I | 1小时 | 1000 |
| 丰收祝福 | 原版经验增加10% | 1小时 | 2000 |

费用为可调整的初始值，请按服务器资金产出配置。首版不提供掉落翻倍、金币加成或战令经验加成。

## 规则

- 购买需二次确认，购买后不退款；同类续时，不叠加等级。
- 按现实时间到期，离线、停服不暂停，重启从数据库恢复。最多累计6小时。
- 默认等级1/5/10分别开放1/2/3个同时生效槽位。已生效增益不会因降级撤销，新增购买受当前等级限制。
- 当前工会成员才能享受；退会、被踢或解散后不再补充效果（最多约1秒检查延迟）。
- 工会战参赛、旁观等受限状态下停止增益；入战快照前主动移除本模块效果。
- 不覆盖玩家已有的同类药水/信标效果，即使其等级较低；外部插件替换效果后不再由工会模块清除。工会效果每秒检查，最长仅持续3秒，进程异常后也会自然失效。
- 原版经验监听 `PlayerExpChangeEvent`，小额经验按玩家累计小数；不修改战令/点券，也不保证能拦截其它插件直接设置经验值的API。
- 跨服共用数据库，Redis消息加速刷新，10秒轮询兜底。切服后由目的服补充剩余效果。

## 配置

独立 `buffs.yml`，支持共享配置及热重载：

- `enabled`：总开关。
- `purchase-rank`：最低购买职位 MEMBER / OFFICER / LEADER，无权限节点绕过。
- `max-duration-seconds`：最长累计时间。
- `slots-by-level`：达到对应等级后的槽位数（1～4）。
- `buffs.<id>`：`enabled`、`name`、`effect`、`level`、`cost`、`duration-seconds`、`experience-bonus`。
- 支持效果 SPEED / HASTE / WATER_BREATHING / EXPERIENCE，最多4个预设，药水等级1～2。费用须大于0，经验加成范围0～1。

禁用或移除某个增益后不再施加效果，已购到期时间保留。修改同ID配置会影响尚未到期的购买；调整前应告知玩家。

## 存储与购买一致性

`guild_buffs` 保存工会、增益ID及到期时间。购买事务锁住工会行，重新读取购买人职位、等级、资金和有效期，再原子扣款并保存续时时间；失败回滚。SQLite/MySQL共用相同SQL，不依赖Redis锁完成扣款。解散后读取时排除不存在的工会。

不支持旧版本与新版本同时编辑同一玩法数据的完整一致性保证。真实Paper药水来源冲突、MySQL并发及多服切换需在测试服联调。
